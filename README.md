# Self-Deprecated Scoop bucket

Manifests for Self-Deprecated tools, published automatically by each tool's release.

```powershell
scoop bucket add self-deprecated https://github.com/self-deprecated/scoop-bucket
scoop install self-deprecated/sd
```

| App | Tool |
| --- | --- |
| `sd` | [self-deprecated/sd](https://github.com/self-deprecated/sd), a project task dispatcher |
